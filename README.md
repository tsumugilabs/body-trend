# からだ記録

体重・体脂肪率・骨格筋率・腹囲を毎日記録し、目標までの進み具合をグラフで確認するシンプルな減量記録アプリです。
スマートフォン向けの PWA で、データは端末のブラウザ（localStorage）にだけ保存されます。

## 機能

- **ホーム**: 現在の体重・体脂肪率・骨格筋率・腹囲、目標日までの残り日数、開始からの体重変化、目標体重までの差
- **推移グラフ**: 体重 / 体脂肪率 / 骨格筋率 / 腹囲の切り替え、7日・30日・90日・全期間、目標値の水平線と目標日の縦線、タップで日付と数値を表示
- **記録する**: 日付（初期値は今日）・体重（必須）・体脂肪率と骨格筋率と腹囲（任意）。同じ日付は更新確認
- **履歴**: 新しい順の一覧、編集・削除（削除は確認あり）
- **設定**: 開始日・目標日・目標体重・目標体脂肪率・目標骨格筋率・目標腹囲

## 開発

```bash
npm install
npm run dev        # 開発サーバー
npm test           # テスト（Vitest）
npm run typecheck  # 型チェック
npm run build      # 本番ビルド（dist/）
npm run preview    # ビルド結果の確認（Service Worker も動作）
```

開発サーバーでは、初回画面と設定画面に「サンプルデータ」ボタンが表示されます。本番ビルドには表示されず、空の状態から始まります。

アイコンを作り直すときは `npm run icons` を実行します（`public/` に出力）。

## 入力チェック

| 項目 | エラー（明らかな入力ミス） | 確認を表示 |
| --- | --- | --- |
| 体重 | 20kg 未満 / 300kg 超 | 30kg 未満 / 200kg 超、前回から 5kg 以上の変化 |
| 体脂肪率 | 1% 未満 / 75% 超 | 3% 未満 / 60% 超、前回から 8pt 以上の変化 |
| 骨格筋率 | 5% 未満 / 70% 超 | 15% 未満 / 60% 超、前回から 8pt 以上の変化 |
| 腹囲 | 30cm 未満 / 200cm 超 | 50cm 未満 / 150cm 超、前回から 10cm 以上の変化 |

数値は小数点第1位まで。全角数字や「,」の小数点も受け付けます。未来の日付は記録できません。

## GitHub Pages で公開する

1. GitHub にリポジトリを作成して push する
2. リポジトリの **Settings → Pages → Build and deployment** で Source を **GitHub Actions** にする
3. `main` ブランチへの push で `.github/workflows/deploy.yml` がテスト・ビルド・公開を行います

`vite.config.ts` の `base` は相対パス（`./`）なので、リポジトリ名に関係なく動作します。

## データについて

- 保存先: `localStorage` の `metabolic.records.v1`（記録）、`metabolic.goal.v1`（目標）、`metabolic.meta.v1`（最終バックアップ日時）
- 読み込めないデータがあってもアプリは起動し、正しく読めた記録だけを表示します。元のデータは `<キー名>.broken` に退避します
- ブラウザのサイトデータを消去すると記録も消えます

### 記録を消さないための仕組み

- **ホーム画面に追加して使う**: iPhone の Safari はタブで使っているとしばらく開かなかったときに保存データを消すことがあります。ホーム画面に追加したアプリはその対象外です。設定画面に起動方法と追加方法を表示します
- **保存データの保護**: データができたら `navigator.storage.persist()` でブラウザに自動削除しないよう依頼します
- **バックアップ**: 設定画面から JSON ファイルとして保存（スマートフォンでは共有シート経由）し、設定画面または初回画面から復元できます。記録が7件以上あり30日以上バックアップしていないと、ホームでお知らせします
- **古い画面による上書きを防ぐ**: 保存のたびに保存済みの最新データを読み直してから変更を加えます。別のタブの変更も画面に反映します
- **「元に戻す」で新しい変更を巻き戻さない**: 取り消せるあいだに別の画面が加えた変更（追加・更新・削除）は、元に戻しても残します

### 削除時の確認

- 1件の削除: 削除する記録の内容を表示して確認し、削除後は「元に戻す」で取り消せます
- すべて削除: 「削除」と入力するまで実行できません。削除後も「元に戻す」で取り消せます。最終バックアップ日時も消し、消したデータのバックアップを「最新」として扱わないようにします
- 復元で消える記録がある場合: バックアップに同じ日付がない記録（＝復元で消える記録）の件数と日付を表示し、「復元」と入力するまで実行できません
- 危険な操作の確認ダイアログは「キャンセル」が初期選択です
